# Security Policy

## Reporting a Vulnerability

If you discover a security issue in `yeremi/cli-standards`, please report it privately to `yeremiloli@yahoo.com`.

Please include:

- A description of the issue
- Steps to reproduce it
- The affected version or commit, if known
- Any proof of concept, logs, or screenshots that help validate the report

Please do not disclose the issue publicly until it has been reviewed and addressed.

## Response Targets

We aim to:

- Acknowledge reports within 48 hours
- Provide an initial assessment within 5 business days
- Publish a fix or mitigation as quickly as the issue complexity allows

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Scope

This package is a PHP_CodeSniffer standard. Relevant security reports include issues that could lead to unsafe code execution, malicious file handling, unsafe external process behavior, or supply-chain/distribution risks in the package itself.
